# University Exam Timetabling Dataset - 3 Algorithm Version

This version is edited for 3 algorithms only:

1. Greedy / DSATUR
2. Simulated Annealing
3. CSP Backtracking

Pipeline:
Dataset -> Conflict Graph -> Greedy/DSATUR -> Simulated Annealing -> Room Allocation -> CSP Invigilation -> Final Output

The dataset includes 5 academic sessions, 6 departments, students, courses, enrollments, teachers, rooms, timeslots, conflict edges, sample timetable, room allocation, invigilation roster, and teacher load summary.
